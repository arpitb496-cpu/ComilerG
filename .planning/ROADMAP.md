# 🗺️ CompilerG - Development Roadmap

## Milestone 1.0: Foundation & Stability (COMPLETED)
- [x] Monaco Editor multi-CDN integration with zero-latency fallback textarea.
- [x] Support 15+ programming languages with Judge0 compiler IDs and starter templates.
- [x] Standard Input (STDIN) execution and metrics tracking (time, memory, status badges).
- [x] Local Python 3 development server with CORS and MIME support.
- [x] Responsive layout with draggable splitter and glassmorphic UI.
- [x] Resolve Kotlin boilerplate backtick escaping syntax issue.
- [x] Normalize Monaco theme handling (`compilerg-dark` / `compilerg-light`).
- [x] Integrate Ralph Loop verification engine (`scripts/ralph_loop.js`).
- [x] Configure CodeRabbit review profiles (`.coderabbit.yaml`).
- [x] Configure Roo Code development modes (`.roomodes`, `.clinerules`).
- [x] Establish GSD Core project tracking (`.planning/`).

## Milestone 1.1: Advanced Features (UPCOMING)
- [ ] Multi-file tab support (e.g. `main.py`, `utils.py`).
- [ ] Code sharing via URL hash or pastebin backend.
- [ ] Execution history and saved snippets in localStorage.
- [ ] Dark / Light theme toggle micro-animations.
- [ ] Unit testing harness for user code runner.
